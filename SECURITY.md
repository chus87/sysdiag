# Seguridad

No publiques vulnerabilidades de SYSdiag en un issue público.

Utiliza **GitHub → Security → Report a vulnerability** para realizar un reporte privado. Incluye versión, plataforma, impacto y pasos de reproducción saneados. No adjuntes credenciales reales.

La política técnica, modelo de amenaza y límites del principio read-only están documentados en [`docs/SECURITY.md`](docs/SECURITY.md).
